# Landing page renders and is usable — evidence

> **Feature:** `DJERP-010` · **Scenario:** `verify/scenarios/smoke-home.yml` · **Generated by:** `node verify/runner.mjs --feature DJERP-010 --stamp --by agent` against `http://127.0.0.1:8765` on 2026-11-16 (UTC), plus before/after captures of `main` (c504342) and this branch; the scenario images were re-captured on 2026-11-21 against a fresh database on `http://127.0.0.1:8766` (`node verify/runner.mjs --only smoke-home`) after the header nav gained the Workspace and Simulation console links · **Result:** PASS on desktop and mobile

A visitor lands on `/` of a fresh database: the page names itself ("Get started"), lists the setup steps instead of advertising the admin's add form, maps each API area to its section of the Swagger UI, gets the skip link as the first Tab stop, and can file an "Improve this page" report against `bamr87/djangoerp`. With a company on file, its currency badge now reads at WCAG AA contrast in light mode.

The local run used port 8765 because 8000 was taken on the verifying machine; `verify/verify.yml` starts CI's copy on 8000. Every step passed on both viewports with no console errors and no horizontal scroll (`scrollWidth` equals `clientWidth`: 1280 and 390). After one Tab, the focused element is the skip link, 12 px from the top of the viewport on both (`skip_link_top_px_when_focused` in [`report.json`](report.json)). A separate check at 390×844 pressed Enter on it: the URL became `#main-content`, focus moved to `<main id="main-content">`, and the next Tab landed on the table's first link (`/swagger/#/auth`), past the header nav.
